## Deployment Configuration (Netlify)

This repository is pre-configured with `netlify.toml` for seamless 1-click continuous deployment on Netlify:

- **Build Directory:** `.` (Static HTML5 / Vanilla JS)
- **Caching Policy:** 1-year immutable header caching for static assets in `/assets/`
- **Security Headers:** Strict referrer policy, no-sniff, and clickjacking protection
